One-line review of my Monday, for the make.fun competition
**Monday Reviewed in One Line** (`u-zeroxfive-monday-reviewed-in-one-line-e55de3c1`).

## The entry

> Monday: alarm at 6, inbox at 214 by 9, and a 'quick sync' that ate my whole lunch — one star, would not Monday again.

117 characters, one line, inside the 1–200 gate.

## Why this line

It reviews a real Monday, not a generic complaint: a 6am alarm, an inbox
already at 214 by 9, and a "quick sync" that swallowed lunch whole. The
turn lands on the last words — a one-star review that refuses to Monday
again — the kind of line you repeat to a coworker the next morning.

## Run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
Node 22+, standard library only, no network, no dependencies.
